# multimodal-ai-driven-document-pipeline

An event-driven n8n workflow that ingests, classifies, and analyzes multi-modal files from Google Drive using OpenAI Vision, featuring automated Google Sheets logging and confidence-gated human-in-the-loop email alerts.
